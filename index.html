パターン3（GitHub Web画面）での反映手順

  1. 上のボタンから 「index.html 保存」 をクリックしてダウンロードします（PCの「ダウンロード」フォルダに保存されます）。
  2. ブラウザでご自身の GitHub リポジトリページ を開きます。
  3. 画面右上寄りの 「Add file」 ➔ 「Upload files」 をクリックします。
  4. ダウンロードした index.html をドラッグ＆ドロップします。
  5. 画面下部の「Commit changes」欄で緑色の 「Commit changes」 ボタンを押せば即座に反映完了です！
